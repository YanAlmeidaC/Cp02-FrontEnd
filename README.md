## Descrição

Projeto desenvolvido para a disciplina de Front-End, com o objetivo de criar um site multipágina para uma empresa fictícia de viagens chamada TripWay.

## Evolução do Projeto

No Checkpoint 1, o foco foi a estrutura HTML, páginas, navegação, formulário e colaboração com GitHub.

No Checkpoint 2, o projeto foi evoluído com CSS externo, identidade visual, layout com Flexbox, cards estilizados, formulário organizado e responsividade para desktop, tablet e celular.

## Tecnologias Utilizadas

- HTML5
- CSS3
- Flexbox
- Git
- GitHub

## Páginas

- Home
- Destinos
- Pacotes e Serviços
- Contato e Reserva

## Recursos Aplicados no Checkpoint 2

- CSS externo
- Variáveis CSS com `:root`
- Reset básico com `box-sizing: border-box`
- Estilização de header, nav, links, cards, botões e formulário
- Uso de pseudo-classe `:hover`
- Layout com Flexbox
- Medidas relativas como `%`, `rem` e `max-width`
- Responsividade com `@media`
